Что делать с результатом

Скопируй диагностический журнал и пришли его в чат. Журнал может содержать данные устройства — просматривай его перед отправкой. Сырые USB-пакеты обычно не являются личными данными, но не стоит публиковать серийные номера устройства.

Тест работает только в защищённом контексте: HTTPS (например, GitHub Pages) или localhost, в Chrome/Edge с поддержкой Web Serial. Открытие обычного HTML-файла двойным щелчком может не дать доступа к порту.
